# مُنطلق (Prompt)

المكتبة العربية للمُنطلقات الذكية: موقع ثابت بالكامل بواجهة عربية RTL، مع مكتبة للمنطلقات ولوحة تحكم لإدارتها.

**النسخة المنشورة:** <https://zahalqaai.github.io/montalaq-prompt/>

**لوحة التحكم:** <https://zahalqaai.github.io/montalaq-prompt/admin.html>

## التشغيل

من داخل مجلد المشروع:

```bash
python -m http.server 4173 --bind 127.0.0.1
```

ثم افتح:

- الموقع: <http://127.0.0.1:4173/>
- لوحة التحكم: <http://127.0.0.1:4173/admin.html>

كلمة مرور لوحة التحكم الافتراضية هي `11111`. يمكن تغييرها من **الإعدادات والنسخ الاحتياطي ← كلمة مرور لوحة التحكم** بعد الدخول.

> عند النشر على GitHub Pages، غيّر كلمة المرور الافتراضية فورًا من إعدادات لوحة التحكم.

## النشر على GitHub Pages

يُنشر الموقع من الفرع `main` ومن جذر المستودع مباشرة. وجود ملف `.nojekyll` يمنع معالجة الملفات عبر Jekyll ويضمن تقديم الموقع كملفات ثابتة.

يمكن أيضًا فتح `index.html` مباشرة من القرص. في هذه الحالة يستخدم الموقع النسخة المدمجة من البيانات لأن المتصفح يمنع قراءة JSON المحلي عبر `file://`.

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` | واجهة الزائر: المكتبة، البحث، التفاصيل، المفضلة، الإعجاب، ونموذج الاقتراح |
| `admin.html` | لوحة التحكم: النظرة العامة، إدارة المنطلقات، مراجعة الاقتراحات، الإعدادات |
| `js/app.js` | النواة المشتركة، النسخة المدمجة من البيانات، ومنطق واجهة الزائر |
| `js/admin.js` | منطق لوحة التحكم والعمليات على البيانات |
| `data/prompts.json` | المصدر الأساسي لبيانات المنطلقات (12 منطلقًا) |

## التخزين

تُحفظ التغييرات في `localStorage` تحت المفاتيح التالية:

- `montalaq_prompts_v1`
- `montalaq_favorites_v1`
- `montalaq_liked_v1`
- `montalaq_suggestions_v1`
- `montalaq_admin_password_v1` (بصمة كلمة مرور لوحة التحكم)

`data/prompts.json` هو مصدر البيانات الافتراضي. عند تعديله، حدّث نسخة `SEED_PROMPTS` المدمجة في `js/app.js` أيضًا ليبقى وضع `file://` متزامنًا.

## اتجاه النص

يبقى هيكل الموقع RTL دائمًا. يُطبَّق `detectDirection(text)` على حقول المحتوى فقط:

- `prompt_text`
- `explanation`
- `example_result`

فتتحول هذه الحقول تلقائيًا إلى RTL أو LTR بحسب النص، بما في ذلك المعاينة الحية داخل محررات النصوص.

## لوحة التحكم

تتيح اللوحة:

- الدخول بكلمة مرور، مع بقاء الجلسة مفتوحة في التبويب الحالي حتى تسجيل الخروج.
- تغيير كلمة المرور من صفحة الإعدادات.
- إضافة المنطلقات وتعديلها وحذفها.
- إضافة صورة كمثال على النتيجة عبر الرفع أو السحب أو اللصق من الحافظة (`Ctrl + V`) أو زر **لصق من الحافظة**.
- البحث والتصفية والترتيب.
- مراجعة اقتراحات الزوار واعتمادها أو حذفها، مع عرض الصور المرفقة بها.
- تصدير البيانات واستيراد ملف JSON.
- استعادة البيانات الافتراضية.
- عرض إحصاءات المكتبة وحالة التخزين المحلي.

## صور أمثلة النتائج

يمكن أن يكون مثال النتيجة نصًا أو صورة، أو الاثنين معًا.

- الصيغ المدعومة: `PNG` و`JPG` و`WebP` و`GIF`، بحد أقصى 8 ميجابايت للصورة الأصلية.
- تُضغط الصورة تلقائيًا إلى WebP وبحد أقصى 1400 بكسل للضلع الأطول قبل الحفظ.
- يمكن رفع الصورة أو سحبها إلى منطقة الرفع، أو لصقها مباشرة من الحافظة بـ `Ctrl + V` أثناء فتح محرر المُنطلق.
- تُحفظ الصورة داخل بيانات المكتبة كـ Data URL، لذا تتضمنها نسخة JSON المصدَّرة ويعيد الاستيراد عرضها.
- عند إضافة صورة فقط دون نص، يُضبط نوع المثال تلقائيًا على «صورة».
- يمكن للزائر أيضًا إرفاق صورة مع اقتراحه من نموذج «شاركه مع الجميع» بالرفع أو السحب أو اللصق، وتظهر الصورة داخل لوحة التحكم عند مراجعة الاقتراح.

> مساحة `localStorage` محدودة (نحو 5 ميجابايت لكل أصل). الصور المرفوعة تستهلك جزءًا من هذه المساحة، لذا يُفضَّل استخدام صور معتدلة الحجم. إذا امتلأت المساحة تظهر رسالة خطأ عند الحفظ ولا تُفقد التعديلات من المحرر.

> **ملاحظة أمنية:** الموقع ثابت بالكامل ويعمل دون خادم خلفي، لذلك حماية لوحة التحكم هي حماية واجهة محلية وليست مصادقة خادم. كلمة المرور محفوظة كبصمة في `localStorage`، ولا تمنع من يملك وصولًا كاملًا لملفات المشروع أو أدوات المتصفح من تجاوزها. أما الاستخدام الحقيقي متعدد المستخدمين فيحتاج خادمًا مع مصادقة وصلاحيات.
